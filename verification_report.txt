Scope and version
Owner-requested removal of old config/function compatibility and redundant code.
Version increments exactly 0.0.1 from 0.0.34; earlier delivered ZIPs and
source trees are untouched. Inspected complete source/config/docs/tests before edits.
Every required project path remains; no file was added or removed in this version.

Breaking changes and removals
- Only completion/live reporting config sections are supported. The root mqtt
  translator, publish_timeout/keepalive/retain/tls_insecure handling, null/string
  normalization and historical topic/QoS defaults were removed. Unsupported keys
  now fail validation; use the complete current examples and completion.timeout.
- Canonical parse_completion_config/MQTTConfig and internal STATE.completion replace
  parse_mqtt_config/MqttConfig/STATE.mqtt. The unused app __version__ alias is gone.
- Removed get_upload_remote_quota_entries, RemoteQuotaFile,
  get_filtered_local_upload_size, join_relative_path, build_mqtt_status_payload,
  unused sleep_after_step and one-line publish_result_payload.
- Removed cleanup.py's obsolete execute_delete_plan re-export/__all__ and unused
  imports. Current callers import the implementation from delete_plan.py directly.
- Removed an unread reservation-byte cache. The planned upload list and its lock
  remain; actual quota arithmetic, reservations and displayed values are preserved.
- Removed the ignored positional refresh_live argument; finish uses clear_current.
- Completion uses standard name/job/version rather than duplicate script_name/
  application/application_version fields. All standard fields, event, failed_remotes,
  remotes/stages/errors and progress remain. HA automation uses standard fields.

Deduplication and safety
One shared unknown-key validator covers reporting, root, thread, upload and cleanup
rule settings. One option partitioner replaces the two near-identical source/transfer
scanners, preserving order and values. Current code uses real implementations rather
than compatibility wrappers. Actual backend wrappers (crypt/alias/etc), deletion
modes, age/size/count checks, source selection, exact upload lists, quotas, locking,
barriers, failure isolation and signal supervision remain intact.
