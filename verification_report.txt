Changes and compatibility
- Replaced six repeated stage pool/join/error handlers with run_remote_workers.
  Phase callers retain candidate selection, worker limits, complete barriers and
  prerequisite skips. StopAwareExecutor still handles cancellation and queued jobs.
- Reused the shared STAGES tuple in completion/result classification.
- Removed unused LivePreview.record_dataset, _dataset_list, completion builder
  dataset keyword arguments, PublishResult.sent and unused Sequence type import.
  Current rclone paths use atomic bulk update, validated extra and status directly.
  Optional JSON array types, required standard fields and core-field protection
  remain validated. Publisher wire schema, TLS, credentials and deadlines remain.
- Removed completed_stages/total_stages compatibility fields and duplicate live
  remote_jobs[].stages. Detailed steps/activity/metrics remain; console and
  completion remotes[].stages preserve actual result-stage accounting.
- Removed card support for historical failed status spelling and old activity-less
  packets. Current manufacturer/role recognition and heartbeat/result fallback
  remain. Install the matching app/card together; custom consumers of the removed
  detailed-extension fields must use detailed steps or completion remotes[].stages.
- Old root mqtt config conversion and obsolete aliases were already absent in
  0.0.36; verified they stay absent/rejected. Current config options
  and both complete config examples remain byte-identical.
